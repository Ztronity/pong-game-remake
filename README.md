# pong-game-remake
This is a remake of the game Pong, an arcade classic from 1972.

## Instrução para inicio do jogo:

iniciar o ambiente virtual:
    
- acessar a pasta do jogo:
  cd pong-game-remake
- ativar o ambiente virtual:
  source pong/bin/activate
- executar o arquivo .py:
  python3 jogo-pong-8bits.py #caso seja linux
  python jogo-pong-8bits.py #caso seja windows
